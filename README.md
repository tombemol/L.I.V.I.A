# L.I.V.I.A.

**Leitura Inteligente e Visualização de Informações de Armazenamento**

Aplicativo desktop para Windows focado em análise visual de armazenamento, identificação do que está ocupando espaço e recomendações inteligentes de limpeza segura.

> Projeto em bootstrap. O desenvolvimento da primeira versão acontece na branch `feature/bootstrap-desktop`.
