# PRODUCT

## Produto

**L.I.V.I.A. — Leitura Inteligente e Visualização de Informações de Armazenamento**

Aplicativo desktop para Windows que ajuda uma pessoa a entender por que o disco está cheio e quais arquivos merecem revisão.

## Problema

Ferramentas tradicionais de análise de disco são muito úteis, mas frequentemente apresentam densidade visual alta, linguagem técnica e pouca orientação para a próxima decisão.

O usuário não quer apenas saber que uma pasta tem 84 GB. Ele quer entender o que aquilo significa e o que pode fazer com segurança.

## Usuários

- pessoas com SSD quase cheio;
- gamers com bibliotecas, instaladores e arquivos grandes espalhados;
- desenvolvedores com artefatos de build e caches;
- usuários comuns que não sabem quais arquivos podem revisar sem quebrar o Windows.

## Resultado esperado

Em menos de um minuto após a análise, o usuário deve conseguir responder:

1. O que mais ocupa espaço?
2. Quais tipos de arquivo dominam o disco?
3. Quais arquivos individuais são os maiores?
4. Existe algo antigo ou temporário que merece revisão?
5. A ferramenta está sugerindo algo arriscado?

## Princípios

- explicar antes de recomendar;
- recomendação não é ordem de exclusão;
- silêncio é melhor que uma sugestão inventada;
- uma ação principal por estado da tela;
- dados locais permanecem locais;
- áreas do sistema são tratadas com cautela;
- números importantes aparecem antes dos detalhes.
