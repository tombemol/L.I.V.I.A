Política de Privacidade

A L.I.V.I.A. foi projetada para analisar armazenamento no próprio dispositivo. Não exigimos conta, não vendemos dados e não usamos telemetria ou anúncios dentro do aplicativo.

Última atualização: 19 de setembro de 2026

1. Dados analisados localmente

Durante uma análise, a L.I.V.I.A. pode ler nomes e caminhos de arquivos, tamanhos, datas, tipos, hashes necessários para confirmação de duplicatas e outras informações de sistema relacionadas ao armazenamento escolhido pelo usuário.

Esses dados são processados localmente para construir o índice, snapshots e visualizações. O conteúdo do índice de arquivos não é enviado para servidores do projeto.

2. Dados persistidos no dispositivo

Índices e snapshots podem ser salvos localmente para permitir histórico, atualização incremental e recuperação de estado. Esses arquivos permanecem no dispositivo do usuário e podem ser removidos ao limpar os dados da aplicação ou desinstalá-la.

3. Conexões de rede

A versão desktop pode acessar a API e os arquivos do GitHub Releases para verificar a existência de atualizações, exibir notas de versão e, quando solicitado, baixar um instalador. A L.I.V.I.A. não anexa o índice de arquivos, nomes de arquivos ou conteúdo analisado a essas requisições.

O site do projeto é hospedado no GitHub Pages e consulta o GitHub Releases para localizar downloads recentes. GitHub pode receber metadados técnicos normais de uma requisição web, como endereço IP, user agent e horário, conforme a política de privacidade do próprio GitHub.

A assinatura de código pela SignPath acontece durante a construção e publicação de releases. A análise de armazenamento em execução não envia conteúdo do usuário para a SignPath.

GitHub General Privacy Statement ↗ SignPath Foundation ↗

4. Android e permissões de armazenamento

No Android, o usuário pode autorizar uma pasta pelo Storage Access Framework ou conceder acesso amplo ao armazenamento compartilhado quando esse modo estiver disponível. Essas permissões existem para permitir a análise local do armazenamento autorizado.

A L.I.V.I.A. não usa essas permissões para enviar os arquivos analisados ao projeto. Áreas privadas protegidas de outros aplicativos continuam sujeitas às restrições do Android.

5. Telemetria, publicidade e venda de dados

A aplicação não inclui sistema próprio de analytics, perfilamento comportamental, publicidade ou venda de informações pessoais. Não existe conta obrigatória da L.I.V.I.A.

6. Links e serviços externos

Ao abrir GitHub, páginas de download, links de documentação ou meios externos de apoio ao projeto, o usuário passa a interagir diretamente com o serviço escolhido. O tratamento de dados nesses serviços é regido pelas respectivas políticas.

7. Contato e transparência

Dúvidas ou relatos relacionados à privacidade podem ser enviados pelo repositório público da L.I.V.I.A. Mudanças materiais nesta política serão publicadas junto ao código e ao site do projeto.
