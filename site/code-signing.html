Code signing policy

Esta página define como releases oficiais Windows da L.I.V.I.A. são produzidas, aprovadas e identificadas quando assinadas.

Projeto: L.I.V.I.A. · Licença MIT · Repositório público

Code signing provider

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

O certificado é usado exclusivamente para artefatos oficiais da L.I.V.I.A. produzidos a partir do repositório tombemol/L.I.V.I.A.

Alterações de terceiros devem passar por revisão antes de entrar na branch principal. Cada solicitação de assinatura deve ser aprovada manualmente pelo signing approver.

Origem e build dos artefatos

Releases oficiais são construídas por workflows versionados no próprio repositório. O código-fonte, scripts de build e configuração de CI usados para produzir os binários permanecem públicos.

Somente artefatos produzidos a partir do código oficial do projeto podem ser submetidos para assinatura. Binários modificados ou recompilados por terceiros não são releases oficiais da L.I.V.I.A., mesmo que usem o mesmo código-fonte.

Distribuição e verificação

O canal oficial de distribuição é a página de GitHub Releases vinculada abaixo. A página pública de downloads aponta para esse canal e os artefatos publicados pela pipeline recebem checksum SHA-256.

Releases anteriores ao início da assinatura, builds experimentais ou artefatos de desenvolvimento podem permanecer sem assinatura. A ausência de assinatura deve ser tratada como característica daquela build, não como evidência de que um arquivo externo seja oficial.

Página oficial de downloads → GitHub Releases ↗

Privacidade

A L.I.V.I.A. processa o índice de armazenamento localmente. A aplicação não transfere o conteúdo do índice, nomes de arquivos ou arquivos analisados para a SignPath durante a execução. Conexões externas usadas pelo updater e pelo site estão descritas na política de privacidade.
