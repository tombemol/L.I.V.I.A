Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

As releases oficiais Windows marcadas como assinadas são produzidas a partir do código-fonte do repositório oficial e seguem a política pública de assinatura do projeto. Releases antigas ou de desenvolvimento podem permanecer sem assinatura enquanto a integração estiver em implantação.

A assinatura serve para verificar a origem do binário. Ela não transforma builds de terceiros em releases oficiais e não autoriza alterações fora do fluxo de publicação do projeto.

Checksums

Os artefatos publicados pela pipeline recebem arquivos .sha256. Compare o hash do arquivo baixado com o checksum publicado na mesma release antes de instalar, especialmente em builds ainda não assinadas.
